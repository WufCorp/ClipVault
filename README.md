# ClipVault

**Менеджер истории буфера обмена для Windows, который не тормозит, не шпионит и умеет искать.**

Ловит текст, картинки и файлы, хранит историю локально и открывается по `Ctrl+Shift+V`
с мгновенным полнотекстовым поиском.

## Скачать

**[⬇ Скачать последнюю версию (Releases)](https://github.com/WufCorp/ClipVault/releases/latest)**

Скачайте `ClipVault_x64-setup.exe`, запустите установщик, готово. Приложение стартует в фоне,
значок появляется в трее. Скопируйте что-нибудь и нажмите `Ctrl+Shift+V`.

Требуется Windows 10/11 x64 и WebView2 Runtime (в актуальной Windows уже установлен).
Обновления прилетают автоматически и отключаются в настройках.

## Что умеет (бесплатно)

- **Нативный захват без polling.** Отдельный поток слушает системные события буфера, ноль холостого хода.
- **Текст, картинки и файлы.** Картинки хранятся как PNG, в базе только путь и превью.
- **Дедупликация.** Повторное копирование не плодит дубли, а поднимает запись наверх.
- **Мгновенный поиск (SQLite FTS5).** Полнотекстовый, с кириллицей и префиксным поиском на лету.
- **Окно истории по `Ctrl+Shift+V`.** Вкладки (всё / закреплённые / текст / фото), превью, время, счётчик копирований, светлая и тёмная тема.
- **Закрепление, удаление, контекстное меню, простой экспорт TXT/JSON.**
- **Пауза записи и игнор-список приложений** для паролей и приватных данных. Безопасность всегда бесплатна.
- **Трей, автозапуск, один экземпляр, авто-обновления.**

Лимит истории в бесплатной версии: 200 элементов.

## Приватность

- Данные хранятся **только локально**, в `%APPDATA%\ClipVault\`. Нет сервера, аккаунта и облака.
- **Единственный сетевой запрос во всём приложении это проверка обновлений.** Уходит только версия
  и платформа, ничего из истории. Запрос **отключается** тумблером в настройках (режим паранойи = ноль сети).
- Нет телеметрии, нет аналитических SDK, нет стороннего ПО в установщике.
- Лицензия проверяется офлайн подписью Ed25519, без сервера активации.

## Стек и архитектура

**Rust + Tauri 2** (бэкенд) · **TypeScript + Vite** (фронтенд) · **SQLite + FTS5** (хранилище).
Tauri вместо Electron ради лёгкого нативного `.exe`, малого расхода RAM и быстрого старта.

```
src-tauri/src/
├── lib.rs              вход: плагины, state, tray, hotkey, слушатель, поведение окна
├── state.rs            Shared: соединение с БД, флаг паузы, guard от цикла
├── clipboard/
│   ├── listener.rs     нативный слушатель + сохранение в БД/PNG
│   ├── reader.rs       чтение текста/картинки/файлов + хэш
│   └── writer.rs       запись обратно в буфер
├── db/
│   ├── schema.rs       схема + FTS5 + миграции
│   └── repo.rs         вставка с дедупом, список, поиск, очистка
├── commands.rs         команды для фронтенда (invoke)
├── license.rs          офлайн-лицензия Ed25519 (публичный ключ зашит)
├── tray.rs · hotkey.rs · window.rs
src/                     фронтенд: main.ts, settings.ts, styles.css, index.html
```

## Сборка из исходников

Нужны **Rust** (stable, `x86_64-pc-windows-msvc`) + **MSVC C++ Build Tools**, **Node.js LTS**
и **WebView2 Runtime**.

```bash
# разработка
npm install
npm run tauri dev

# релизная сборка → src-tauri/target/release/bundle/nsis/
npm run tauri build
```
