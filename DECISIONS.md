## 1. Модель монетизации

- **Free + разовый Pro-unlock.** Без подписки, без аккаунта, без сервера.
- **Цена Pro: `399 ₽` единоразово.** Один SKU. **Без фейковых «старых цен»** — честный ценник (соответствует позиционированию «без мелкого шрифта»).
- **Приём оплаты:** ЮKassa, многоразовый счёт `https://yookassa.ru/my/i/aqiEEXXqILcr/l`.
  Поток покупки: кнопка «Купить Pro» → ссылка ЮKassa → оплата → владелец видит платёж → **вручную генерит и отправляет офлайн-ключ** покупателю (см. §4).
- **Донат (отдельный путь):** кнопка «Поддержать автора» → `https://boosty.to/wufcorp/donate`.
  Размещение: **в шапке окна + в настройках.** Для тех, кому лицензия не нужна, но хочется поддержать.
  ⚠️ Донат и unlock **не смешивать** («задонать и получи Pro» — нет). Два независимых пути.
- **Контакт:** кнопка «Написать автору» → Telegram `https://t.me/WufCorp`. В настройках.

**Почему так:** готовность платить за менеджер буфера низкая (commodity, рядом бесплатный Win+V).
Поэтому: не строим бизнес на обязательной оплате; оптимизируем под ноль текущих затрат
(нет сервера/подписки/ops) и ноль трения в дистрибуции. Доход — тонкий ручеёк (unlock + донат),
ставка на репутацию и органику.

| Область | 🆓 Free | 🔓 Pro (unlock) |

| **Управление** | удалить, очистить всё, простой экспорт TXT/JSON | правила автоочистки, исключения по типу/источнику, импорт, слияние дублей |

- **Free одной фразой:** «нормальный Win+V».
- **Pro одной фразой:** объём + организация + инструменты профи, всё по хоткеям.
- **Принцип:** безопасность (пауза, игнор паролей) — всегда Free, её за деньги не прячем.

## 3. Что выкинули и почему

| Выкинуто | Причина |
|---|---|
| Шаблоны / автозамена (text expansion) | глобальный keyboard-хук + инъекция ввода = отдельный продукт, палится антивирусами, противоречит privacy |
| Авто-вставка (слоты/plain-text «вставляют сами») | та же инъекция ввода — оставили только «подготовить буфер, юзер жмёт Ctrl+V» |
| Сетевое превью заголовка URL | нарушает офлайн / «режим паранойи» |
| Аккаунт / сервер / подписка / 2FA | выбрали офлайн-ключ — сервер не нужен |
| Глубокая кастомизация (прозрачность, семьи шрифтов, 3 режима окна, расположение) | нора полировки, низкий ROI |
| Статистика / «сэкономленное время» | метрика-фантик |
| **Бандл Яндекс.Браузера в установщике** | рушит privacy-позиционирование, палится как PUP антивирусами/SmartScreen/Store, убивает органические каналы. **Файл `installer/yandex.nsh` удалить, хук из `tauri.conf.json` убрать.** |

## 4. Лицензия — офлайн-ключ (без сервера)

- **Формат:** подписанный ключ (Ed25519). Payload `{tier, email}` + подпись **приватным** ключом владельца.
- **Проверка:** **публичный** ключ зашит в `.exe`; подпись проверяется локально, офлайн, навсегда. Подделать без приватного ключа нельзя.
- **Перенос на другой ПК:** ключ **не привязан к железу** → пользователь вставляет ту же строку на любом своём ПК. UI: кнопки «Экспорт лицензии» (в файл/буфер) и «Импорт лицензии».
- **Компромисс:** переносимый ключ можно передать другому. Для утилиты за 399 ₽ — приемлемо (кто ищет чужой ключ, всё равно бы не купил). Мягкий сдерживатель — привязка к email покупателя + показ «Лицензия: …@…» в интерфейсе.
- **Генерация ключей при покупке:** на старте — **вручную** (локальная CLI с приватным ключом → строка покупателю). Автоматизация (webhook → генерация → email) — только если поток продаж вырастет.
- ⚠️ Это **отдельная** пара ключей от ключей подписи обновлений (см. §5). Не путать.

## 5. Авто-обновление через S3

- **Плагин:** `tauri-plugin-updater` (+ `tauri-plugin-process` для перезапуска). Статический хостинг S3 подходит.
- **Поток:** при релизе владелец льёт на S3 `*-setup.exe` + `.sig` + `latest.json`. Приложение проверяет `latest.json` → если версия новее, показывает «Доступно обновление» + заметки → юзер жмёт → скачивание → запуск установщика (NSIS) → перезапуск.
- **UI:** кнопка «Проверить обновления» в настройках + тумблер «Проверять автоматически» (вкл по умолчанию).
- **⚠️ Ключи подписи обновлений — настроить ДО первого публичного релиза.** Публичный ключ зашивается в `tauri.conf.json`; без него обновить уже установленные копии будет **невозможно**.
- **S3:** public-read по HTTPS. CORS не нужен (качает Rust, не браузер). Стоимость — копейки.
  - Провайдер: **Timeweb Cloud S3** (S3-совместимое).
  - Endpoint: `https://s3.twcstorage.ru` · Бакет: `prisma-prava` · Регион: `ru-1`.
  - Публичный URL файла: `https://s3.twcstorage.ru/prisma-prava/<путь>` (объекты релиза — public-read).
  - 🔐 **Access Key / Secret Key в репозиторий и в этот файл НЕ кладём.** Они нужны только владельцу для загрузки релизов; приложению — нет (читает по публичной ссылке). Хранить в переменных окружения / менеджере секретов. Засветившийся ключ — ротировать.
- **Тариф:** для всех (Free + Pro), не Pro-фича.

## 6. Приватность — итог

- Убран бандл Яндекса и телеметрия. Нет сервера лицензий, нет сетевого превью URL.
- **Единственный сетевой запрос во всём приложении = проверка обновлений.** Уходит только версия/платформа, ничего из истории. **Отключается** в настройках.
- «Режим паранойи / полностью офлайн» = авто-проверка обновлений выключена → ноль сетевых запросов.

## 7. Порядок сборки Pro (сначала дешёвая «наживка»)

1. Цвета (дёшево, изолированно, явная ЦА — дизайнеры)
2. Plain-text вставка + URL/UTM
3. Свои хоткеи + запоминание позиции/размера окна
4. Автоочистка по правилам + экспорт/импорт
5. Фасеты поиска (дата/источник/категория/тег, regex)
6. Категории/теги, цветовые метки
7. Слоты (простой вариант — последними)

Дорогое/рисковое — когда деньги уже подтвердились.

---

## 8. Правило стоимости любой будущей фичи

> **«Подготовить буфер, а пользователь вставит сам» — дёшево, ложится в текущую (пассивную) архитектуру.
> «Приложение печатает/вставляет за пользователя» (инъекция ввода) — дорого, ненадёжно между приложениями, палится антивирусами.**

Все оставшиеся Pro-фичи — на «дешёвой» стороне правила.

## 9. Технические зацепки в текущем коде (на этап реализации)

- Внешние ссылки (Boosty, Telegram) → добавить `tauri-plugin-opener` + разрешение в `capabilities/default.json`.
- Авто-обновление → `tauri-plugin-updater` + `tauri-plugin-process`, публичный ключ в `tauri.conf.json`, разрешения в capabilities.
- Версия приложения синхронно в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` + `latest.json`.
- Лимит Free 200 → `DEFAULT_MAX_ITEMS` в `clipboard/listener.rs` (сейчас 1000); гейт Pro-безлимита.
- Удалить `src-tauri/installer/yandex.nsh` и `installerHooks` из `tauri.conf.json`.
- Захват источника (для «игнор-приложения» и фильтра по источнику) → `GetForegroundWindow` в момент захвата (`clipboard/listener.rs`).
